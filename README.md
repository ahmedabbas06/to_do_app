# 📝 To Do App

A simple and user-friendly **To Do App built with Flutter**.

The app helps users organize their daily tasks, manage completed tasks, and customize the app through settings and theme options.

> 🚀 Built as part of my Flutter learning journey, focusing on UI, state management, local storage, reusable widgets, and clean code.

---

## ✨ Features

- 📝 Manage daily tasks
- ➕ Add new tasks
- ✅ View completed tasks
- ⚙️ App settings
- 👤 Profile screen
- 🎨 Theme customization
- 💾 Store task data locally using Hive
- 📦 Save simple key-value data and app preferences using SharedPreferences
- 🔄 State management using Provider / ChangeNotifier
- 🧩 Reusable widgets
- 📱 User-friendly interface

---

## 🛠️ Tech Stack

- **Flutter & Dart**
- **Provider / ChangeNotifier** — State management
- **Hive** — Local database for task storage
- **SharedPreferences** — Local key-value storage and app preferences
